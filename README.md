# Shivneri Army Public School – Results Portal

Teacher data entry and parent/student result lookup.

- `site/` – the website Netlify publishes (index.html + config.js)
- `firestore-rules.txt` – Firebase security rules (paste into Firestore → Rules)
- `SETUP-GUIDE.html` – one-time setup steps

Student results are stored in Firebase, never in this repository.
