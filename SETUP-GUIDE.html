🎓 Putting the Results Portal online

About 30 minutes, once. Everything here is free. You'll need a Google account (for Firebase) and a laptop or desktop.

What's in this folder
  • site/: the website. This is the folder you upload in step 6.
  • firestore-rules.txt: the security rules, which decide who may change results (step 4).
  • Class-I-A-Term-I-results.json: the 22 Class I-A Term I results to import (step 8). Keep this file private. Never put it inside the site folder.

1Create a Firebase project

  1. Go to console.firebase.google.com and sign in with Google.
  2. Click Create a project (or Add project). Name it, for example saps-results.
  3. Turn Google Analytics off (not needed), then click Create project.

2Register the website and copy its settings

  1. On the project home page, click the </> (Web) icon.
  2. Nickname: Results Portal. Leave “Firebase Hosting” unticked. Click Register app.
  3. Firebase shows a code block containing const firebaseConfig = { apiKey: ..., ... }. Keep this page open; you'll copy from it next.

3Paste the settings into config.js

  1. Open site/config.js with Notepad (right-click → Open with → Notepad).
  2. Replace each PASTE… value with the matching value from Firebase. It should end up looking like this, with your own values:
window.FIREBASE_CONFIG = {
  apiKey: "AIzaSy...",
  authDomain: "saps-results.firebaseapp.com",
  projectId: "saps-results",
  storageBucket: "saps-results.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abc123"
};

Save the file. (These values are not secret. Every website that uses Firebase includes them.)

4Create the database and its rules

  1. In Firebase's left menu: Build → Firestore Database → Create database.
  2. Location: choose asia-south1 (Mumbai). Start in production mode. Click Create.
  3. Open the Rules tab. Delete everything there and paste the whole of firestore-rules.txt.
  4. In the pasted text, replace your.email@gmail.com and teacher2@example.com with the real emails of the teachers who will enter results, in small letters, in quotes, separated by commas.
  5. Click Publish.
💡 Only emails in this list can add, edit or delete results. Parents can open one report card at a time, and only by typing the exact class, roll number and name. Nobody outside the staff list can browse all the results.

5Create the teachers' logins

  1. Left menu: Build → Authentication → Get started.
  2. Under Sign-in method, click Email/Password, switch it on, and click Save.
  3. Open the Users tab → Add user. Enter a teacher's email and a password. Repeat for each teacher in your rules list.
⚠️ Create an account for every email in the rules list right away. An email in the list without an account could be claimed by someone else.

6Put the website online (Netlify, free)

  1. Go to app.netlify.com/signup and sign up (“Sign up with Google” is easiest).
  2. Click Add new site → Deploy manually.
  3. Drag the site folder onto the page. In a few seconds you get a link like random-name-123.netlify.app.
  4. To get a nicer name: Site configuration → Change site name, for example saps-results. Your link becomes saps-results.netlify.app.

7Allow teachers to sign in on that link

  1. Back in Firebase: Authentication → Settings → Authorized domains → Add domain.
  2. Type your Netlify address without https, for example saps-results.netlify.app, and click Add.

8First sign-in and import the Class I-A results

  1. Open your website → Teacher entry → sign in with your email and password.
  2. Click ⬆ Import and choose Class-I-A-Term-I-results.json. You should see “Imported 22 results ✓”.
  3. On Home, use 📷 Change photo to add the school photo, and ✏️ Edit on the principal's card to add her passport photo and approved message.
  4. Test as a parent: Check result → Term I, Std I, Section A, Roll 1, name Riya Sharma.

9Share with parents

Send the link (for example on the class WhatsApp group) with this note:

“Open saps-results.netlify.app → Check result → choose the exam, class and section, then type your child's roll number and full name as on the report card.”

Later on

  • New teacher: add their email in the Firestore rules (step 4) and create their login (step 5).
  • Forgotten password: on the sign-in screen, type the email and tap Forgot password?. A reset link arrives by email.
  • Backup: after each exam, click ⬇ Backup on the teacher page and keep the file safe.
  • Updating the website: in Netlify open your site → Deploys → drag the new site folder in. Results are stored in Firebase, so they're not affected.
  • Cost: Firebase's free Spark plan and Netlify's free plan are plenty for a school's results. No card is needed.
